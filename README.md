# Cherry Hub 🍒

A responsive, cherry-blossom-themed games and entertainment homepage. Built with plain HTML, CSS and JavaScript — no build tools or dependencies required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files and folders** from this project (keep `index.html` at the repository root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your site URL will appear in the Pages settings.

## Customise
- Edit the game links and names in `index.html`.
- Add more `.game-card` elements using the same `data-category` and `data-name` attributes.
- Change colours, layout and tree styling in `style.css`.
- Search and category filtering are handled in `script.js`.

## Notes
- Game cards and entertainment buttons link to third-party websites; they do not host or proxy those services.
- YouTube, Prime Video and TikTok open their official websites in a new tab. Some content may require an account or subscription.
- External services, availability and their terms are controlled by their respective providers.
